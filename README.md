This addon requires ClassicAPI by Brues, it will not work without it! https://github.com/brues-code/ClassicAPI

Here is a small addon to add a visual backport of the Quest Log Tracker that was added at some point to the modern WoW client.
I wanted my quest tracker to visually fit in with the Dragonflight Reloaded UI and so this addon was created to fill that gap.

I've implemented the swipe animations, the SFX and visual style. It also provides the following:
	- Normal, Dungeon, Elite and PVP Sections, individually collapsible
	- PfQuest Integration, adds the orb icons that open the world map (same as the pfQuest "Show" button that's in the Quest Log)
	- Right Click menu to open quest details, open quest map (pfQuest) or abandon the quest.
	- Button will appear next to the quest in the tracker if the quest has an item that needs to be used. (Thank you ClassicAPI !)
	- Smart sizing of the quest entries per section with scroll buttons when needed
	- Timed quests have a timer bar on the Quest Tracker
	- Toggle quest tooltips on Mouse Over
	- Toggle quest level in tracker
	- Toggle for quests in your current zone will move to the top of the list and have a blue ** suffix
	- Toggle for quests in your log to move to the top and pulse if you're interacting with the quest finishing NPC

Right click the Quest Tracker header for the options or type /dfqt in game for the toggleable options.
